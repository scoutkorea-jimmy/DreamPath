## 의도적으로 남긴 것 (운영자 확인용)
1. **약관·개인정보처리방침의 「동의 거부권 + 거부 시 불이익」 조항**
   — 개인정보보호법 제22조가 명시 고지를 요구. 여기서 부정어를 빼면 법정 고지가 흐려진다.
   같은 문서라도 면책·의무 서술문(제6조 회원 의무 · 제7조 책임 범위)은 긍정형화했다.
   해당: `legal.privacy_signup` 4항 · `legal.privacy_apply` 5항 · `legal.third_party` 5항 (ko/en)
2. **동작 버튼명** — 취소/Cancel(3곳) · 삭제/Delete · 쿠키 거부/Decline(`Legal.jsx:108`)
   · 신청 상태 라벨 취소됨/CANCELLED(`Member.jsx:560,577`). 기능 식별자라 바꾸면 뜻이 달라진다.
3. **`brand.footer_tagline`** 의 「시간과 장소의 한계를 넘어 / beyond the limits」
   — 수사적으로 이미 긍정문(한계를 **넘는다**)이라 그대로 뒀다.
4. **관리자 화면(`admin.html`)** — 운영자용이라 이번 범위 밖.
5. **내부 오류 코드**(`save_failed` · `invalid_token` 등) — 화면에 보이지 않는 식별자.

## 알게 된 사실 / 걸린 함정
- **부분문자열 충돌**: 치환표를 긴 문장 → 짧은 문장 순으로 정렬하지 않아
  「오류가 발생했습니다.」 규칙이 「네트워크 오류가 발생했습니다.」 안쪽을 먼저 먹었다.
  결과 **「네트워크 잠시 후 다시 시도해 주세요.」** 같은 문장이 6곳. diff 전수 확인으로 잡았다.
  → **일괄 치환은 결과를 눈으로 읽기 전까지 끝난 게 아니다.**
- **파싱 검증 수단 확보**: `@babel/standalone` 을 스크래치패드에 임시 설치해
  `.jsx`·`.js` 전 파일을 파싱할 수 있다. 문구 대량 편집 라운드에서는 배포 전 필수
  (리터럴 하나가 깨지면 사이트 전체가 흰 화면 — v01.098.04 사고 유형).
