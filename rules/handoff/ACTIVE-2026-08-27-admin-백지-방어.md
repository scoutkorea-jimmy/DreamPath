## 설계 근거 (왜 이렇게 하나)
- **세 겹이 겹치는 게 아니라 각자 다른 실패를 잡는다**:
  워치독 = React/Babel 이 **아예 못 뜬** 경우 (에러 경계도 못 잡는다)
  에러 경계 = **렌더 중** 예외
  전역 핸들러 = **이벤트 핸들러/비동기** 예외 (에러 경계가 못 잡는다)
- React 18 UMD 라 에러 경계는 **클래스 컴포넌트**만 가능 (`getDerivedStateFromError`).
- 보고가 렌더를 다시 깨는 **무한 루프**를 막는다 — 세션당 1회.
- **관리자 화면이라 보고 payload 에서 Bearer 토큰을 마스킹**한다. 공개 `/api/errors` 로 나간다.
- 스모크는 **시스템 Chrome** 을 쓴다 (npm 설치 0). Chrome 이 없으면 **"못 돌렸다"**고
  말한다 — 통과로 세지 않는다.
