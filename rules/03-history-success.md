## 2026-08-22 · v01.095.02 — 수신 주소 대소문자 정규화 (실데이터 검증에서 발견)
- **왜**: D1 접근이 복구돼 v01.094.01 카운터 수정을 실데이터로 검증하다가,
  `inbound_emails` 에 **`Partner@koreadreampath.com` 5통과 `partner@koreadreampath.com` 7통이
  따로 쌓여 있는 것**을 발견. Cloudflare 는 발신자가 친 대로의 대소문자를 넘긴다.
  v01.094.01 이전에는 조회가 exact match 라 **대문자 5통이 Partner 탭에서 아예 안 보였다.**
- **어떻게**: 조회는 이미 `LOWER()` 로 고쳐져 있어 지금은 12통 다 보인다(그 수정의 실효 확인).
  재발 방지를 위해 **수신 시점에 소문자로 저장**하도록 `email()` 핸들러 정규화.
- **확인**: `SELECT to_addr, COUNT(*) … GROUP BY to_addr` 로 두 갈래 실측
  (Partner@ 5 · partner@ 7 · info@ 12). 신청 0건 · 뉴스 0건 · 회원 8명도 같이 확인.
- **남은 것**: 기존 5행의 백필(대문자 → 소문자)은 **운영자 확인 대기**. 조회가
  대소문자 무시라 기능상 급하지 않다.

## 2026-08-22 · v01.095.00 — 신청 접수 전면 중단 + 진입 고지 게이트 해제
- **왜**: 운영자가 사이트 현행화를 시작 — 첫 페이지 고지 모달은 내리고, 신청은 전부 막아둘 것.
- **어떻게**: `c.apply_gate.closed` 스위치 신설. 워커가 학생측 제출을 전부 503으로 거절
  (`/api/applications`, `/applications/upload`, `/me/applications/:id/{cufs-reg-no,admission,documents,pay}`).
  폼은 안내 화면으로 대체. `entry_gate.enabled` 기본값 false + KV 명시 기록.
  관리자 토글 2종 추가(지원 탭 · 공지 탭)라 다음 개폐는 배포 없이 가능.
- **확인**: 운영 배포 후 4개 엔드포인트 실제 호출 → 전부 503 `applications_closed`.
  로컬 헤드리스 크롬 → 게이트 미표시 · `/apply` 안내 화면 · 폼 미렌더 · JS 예외 0.
- **부수 작업**: 수신 메일 전량을 `scoutkorea@kakao.com` 으로 자동 포워드하도록 KV
  `email_templates.forward_to` 설정. ⚠️ Cloudflare Destination 인증 필요(운영자 조치).
