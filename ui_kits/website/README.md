# DreamPath Website UI Kit

Interactive, click-through high-fidelity recreation of the DreamPath public website. Components are intentionally cosmetic (not production) but visually accurate to the design system.

## Files
- `index.html` — entry point; wires all components into a single-page-app with view routing
- `App.jsx` — top-level app + router
- `Nav.jsx` — top navigation + language toggle
- `Footer.jsx` — site footer
- `Home.jsx` — landing page
- `About.jsx` — project & team
- `Programs.jsx` — program list + filter
- `ProgramDetail.jsx` — single program page
- `Apply.jsx` — How to Apply + multi-step Apply form
- `Partners.jsx` — partner institutions
- `Stories.jsx` — Success stories
- `News.jsx` — News/blog listing
- `Contact.jsx` — Contact + FAQ
- `copy.js` — ko/en copy data

## Views covered
Home · About · Programs · Program Detail · How to Apply (with multi-step form) · Partners · Success Stories · News · Contact · FAQ
