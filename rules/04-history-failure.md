## 🔴 미해결 · 2026-08-22 · 같은 저장소에서 두 세션이 동시에 작업했다
- **무엇이 벌어졌나**: 이 저장소에서 **다른 Claude Code 세션이 동시에** 안정성 라운드를
  진행 중이었다(글꼴·에디터 CSP 복구, 부트 워치독, 에러 바운더리). 세션 시작 시 git 상태는
  clean 이었고, 작업 중간에 그쪽 변경이 작업트리에 나타났다.
- **그래서 생긴 일 셋**
  1. **버전 번호 충돌** — 그쪽이 `wiki:versions` 에 `v01.097.00` 을 먼저 게시했는데,
     나도 같은 번호를 `version.js` 에 썼다. 위키 게시 단계의 중복 검사(assert)에 걸려서야 알았다.
     → 내 라운드를 `v01.097.01` 로 내렸다.
  2. **내 커밋이 그쪽 `worker.js` 변경을 함께 담았다** — CSP `font-src` 수정이 내
     커밋 메시지 아래 들어갔다. 파일 단위로 `git add` 해도 **같은 파일을 둘이 만지면** 섞인다.
  3. **내 `wrangler deploy` 가 그쪽 미커밋 파일을 배포했다** — 배포는 작업트리 전체를
     올리므로 `index.html`·`editor-loader.js`·`RichEditor.jsx` 의 진행 중 코드가 운영에 나갔다.
     (검증에서 예외 0건이라 현재 문제는 없어 보이지만, **의도한 배포가 아니었다**.)
- **왜 못 막았나**: `git add <파일>` 명시는 **다른 세션이 만지지 않은 파일**에만 유효한
  방어다. 배포에는 아무 방어도 없었다.
- **재시도/개선 조건**:
  - 배포 직전 `git status --short` 로 **내가 만지지 않은 변경이 있는지 확인**하고,
    있으면 배포 전에 운영자에게 알린다.
  - 버전 번호는 `version.js` 를 올리기 전에 **`wiki:versions` 의 최신 페이지를 먼저 조회**해서
    이미 쓰인 번호인지 확인한다.
  - 커밋 전 `git diff --stat <내 파일>` 로 내가 쓴 줄만 들어가는지 눈으로 본다.
  - 근본 해결은 세션당 워크트리 분리(`git worktree`)지만, 배포 대상이 하나라 그것만으로는
    배포 충돌은 못 막는다 — **운영자가 동시 작업을 알려주는 것**이 가장 확실하다.

## 🔴 미해결 · 2026-08-22 · Cloudflare Email Routing 목적지 인증을 코드로 못 함
- **하려던 것**: 수신 메일 전량 `scoutkorea@kakao.com` 자동 포워드를 끝까지 자동화.
- **실패**: 설정(KV `email_templates.forward_to`)은 넣었으나, Cloudflare 는 목적지 주소를
  **사람이 인증 메일 링크를 눌러야** 활성화한다. 로컬 wrangler 토큰에는
  `email_routing:write` 스코프도 없다(`wrangler whoami` 경고에 명시).
- **영향**: 인증 전까지 forward 만 실패하고 메일 자체는 D1 에 정상 보관 + 관리자 메일함에서 열람 가능.
  실패는 관리자 → 오류 로그(`email_worker`)에 남는다.
- **재시도 조건**: 운영자가 kakao 메일함에서 Cloudflare 인증 링크 클릭 → 그 뒤 테스트 메일 1통으로
  forward 성공 확인.

## ⚪ 해결됨 · 2026-08-21 · 메일 본문 차단의 진짜 원인은 특정하지 못함
- **하려던 것**: 크롬이 메일 본문 iframe 을 차단한 정확한 원인 규명.
- **실패**: 워커 CSP 를 그대로 붙인 로컬 재현에서는 srcdoc iframe 이 **정상 렌더**됐다
  (sandbox 유무 3종 모두). 즉 CSP `frame-src` 는 범인이 아니다. 확장 프로그램 등
  운영자 브라우저 환경 요인이 남았지만 원격으로는 확인 불가.
- **어떻게 넘겼나**: 원인 특정 대신 **프레임 의존 자체를 제거**(인라인 렌더). 원인이
  무엇이었든 재발하지 않는 구조로 바꾼 것.
- **교훈**: 통제할 수 없는 환경(브라우저·확장)에 의존하는 구조는, 원인을 못 찾으면
  구조를 바꾼다.
