### 고친 것
1. **만료 토큰이 한 번도 정리되지 않았다** — 세션 39행 중 **35행이 만료분**.
   인증에는 쓰이지 않지만(조회마다 만료 검사) 무한히 쌓이고, DB 덤프가
   유출되면 시도할 토큰 목록이 된다. 비밀번호 재설정·이메일 인증 토큰은 더
   나쁘다 — **쓰고 나서도 남아 있는 1회용 비밀**이다.
   → `expiredTokenCron()` 추가(매시). 테이블 하나가 실패해도 나머지는 돌고,
   실패는 `error_logs` 에 남긴다 — **조용히 멈춘 청소 작업은 할 일이 없는
   청소 작업과 구별되지 않는다.**
   → `error_logs` · `analytics_events` 는 **일부러 쓸지 않았다.** 그것은 기록이고,
   지우면 "이런 건 처음 본다"가 사고로 참이 된다. 보존 기간은 운영자 결정 사항.
2. **배포 전 `.jsx` 구문검사가 없었다** — 빌드 스텝이 없어 파일 하나의 구문
   오류가 SPA 전체를 죽이는데, 그것을 배포 전에 잡는 것이 아무것도 없었다.
   → `rules/tools/jsx-check.mjs` + preflight 연결.
   → **브라우저가 쓰는 것과 같은 버전의 Babel** 로 검사한다(버전을 `index.html`
     에서 읽는다). 다른 파서로 통과시키면 검사가 거짓 안심을 준다.
   → 의존성 0 은 지켰다 — npm install 이 아니라 파일 하나를 `.wrangler/` 에 캐시.
   → **일부러 깨뜨려 실패하는지 확인했다**(Footer.jsx 에 `const broken = (`
     추가 → 종료코드 1). 부정 검사는 못 읽으면 언제나 통과한다.
