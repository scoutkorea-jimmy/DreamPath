  프로그램이 진행중이라고만 해줘. 신규 프로그램이 진행되면 별도로 안내해준다고 정도로"

## 새 메시지 골자
1. 현재 **신규 모집 중인 프로그램은 없다**
2. **기존 프로그램은 진행 중**이다
3. 신규 프로그램이 열리면 **별도로 안내**한다

→ "일시 중단 / paused" 라는 **부정형 프레임을 걷어내고**, 사실 그대로의 상태 안내로 바꾼다.

## 함께 고친 것 (문구가 사실과 어긋나 있었다)
- 본문이 "프로그램 정보는 그대로 열람하실 수 있습니다" 라고 했는데 **프로그램은 어제 내려서 볼 수 없다.**
  → 문장 삭제, 버튼도 "프로그램 살펴보기"(막다른 길) → **문의하기 / 장학 정보 보기**.
- **일시정지 아이콘(⏸)** 은 "고장나서 멈췄다"는 인상을 준다 → **달력 아이콘**(다음 회차 준비 중).

## 🔴 검증 중 발견 — 상단 띠 배너가 되살아나 있었다
- **증상**: `/apply` 스크린샷 맨 위에 `🚧 Under development · Official launch mid-June` 이 다시 떠 있었다.
  2026-08-22 에 분명히 내린 배너다.
- **원인**: KV 는 `notice.enabled=false` 로 정상이었다. 그런데 **문구가 KV 본문이 아니라
  `DEFAULT_CONTENT` 의 것**이었다 — 즉 원격 콘텐츠가 도착하기 전 **첫 페인트가 코드
  기본값으로 그려지고 있었다.** 어제는 KV 만 껐고 코드 기본값은 `enabled: true` 그대로였다.
- **교훈**: **KV 에서 끄는 것과 코드 기본값을 내리는 것은 다른 일이다.** 방문자는 매번
  두 달 지난 배너를 잠깐씩 보고 있었고, KV 가 초기화되면 영구히 돌아왔을 것이다.
  → `DEFAULT_CONTENT.notice.enabled = false` + **기본 문구에서 날짜 제거**
  (코드에 박힌 날짜는 반드시 낡는다 — `entry_gate` 에서 이미 한 번 겪은 함정).
