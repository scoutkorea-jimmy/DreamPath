# 05 · 하지 말 것 (운영자 지시 · 불편 호소)

> **매 라운드 시작 전 필독.** 운영자가 "하지 마" 라고 했거나 불편을 호소한
> 것들이다. 사유까지 적는 이유는, 사유를 모르면 다음에 같은 실수를 다른
> 모양으로 하기 때문이다.
>
> 새 항목은 **맨 위에** 추가한다. 날짜 · 무엇을 · **왜**.

## 2026-08-23 · 콘텐츠 스위치를 **한 곳만** 끄지 말 것
- **무엇**: 배너·게이트·문구를 끌 때 KV 만 고치는 것. **코드 기본값(`DEFAULT_CONTENT`)과
  worker 상수까지** 같이 내려야 한다.
- **왜**: 첫 페인트와 KV 초기화 때는 코드 기본값이 이긴다. 이걸로 **세 번** 당했다
  (배너 · CUFS · 레거시 표기). 이제 `preflight.mjs` 가 막지만, **검사를 건너뛰지 말 것.**

## 2026-08-23 · 외부 서비스 상태를 추정해서 안내하지 말 것
- **무엇**: "인증 메일 링크를 누르세요" 라고 했는데 **애초에 등록도 안 돼 있었다.**
- **왜**: 우리 설정값은 저쪽 상태의 증거가 아니다. **조회해서 확인**하고 말한다.

## 2026-08-27 · 🔴 이모지를 쓰지 말 것 (사용자에게 보이는 모든 곳)

- **무엇**: 화면·메일·알림·문서 어디든 **컬러 그림문자(emoji)를 쓰지 않는다.**
  🎉 📨 🔗 📖 ✅ 🚧 💳 👤 🔒 ⚠️ 같은 것 전부. 새로 넣는 것도, 남아 있는 것을
  그대로 두는 것도 안 된다.
- **왜**: 운영자 지시(2026-08-27) — "홈페이지 톤앤매너와 맞지 않는다." 이 사이트는
  유학 지원이라는 **삶의 결정을 다루는 창구**다. 축하 폭죽과 공사 표지판이 섞이면
  기관으로 보이지 않는다. 정보를 더하지도 않는다: 경고는 이미 색·배경·`role=alert`
  가 전하고, 목록은 이미 라벨이 구분한다.
- **대신 무엇을**:
  - 의미가 필요한 자리 → **lucide 아이콘** (`<i data-lucide="lock" />`).
    공개 `index.html` 과 `admin.html` 둘 다 이미 싣고 있다.
  - 강조가 필요한 자리 → **토큰 색** (`--state-warning` 등) + 말로 쓴 라벨("주의 —").
  - 장식이던 자리 → **그냥 뺀다.**
- **이모지가 아닌 것 — 지우지 마라**: `→ ← ↑ ↓ ↗ ▶ ✓ ✗ ○ ● ★ ☆ ✕ ⛶ ⤡ ↩ ▦ ≡`
  같은 **흑백 타이포그래피 기호**는 이모지가 아니다. 저장소에 `→` 만 332개다.
  일괄 치환으로 이것까지 걷어내면 문서와 UI 가 망가진다. **구분은 성질로 한다 —
  컬러로 렌더되는 그림문자인가.**
- **강제**: `rules/tools/preflight.mjs` 가 UI 파일과 KV 콘텐츠에서 그림문자를
  찾으면 배포를 막는다. 글로만 적은 규칙은 다음 라운드에 잊힌다.

## 2026-08-22 · 요청하지 않은 도구를 함부로 쓰지 말 것
- **무엇**: AgentTool(서브에이전트) · 워크플로 · 딥리서치는 운영자가 **명시적으로
  요청했을 때만** 쓴다.
- **왜**: 세션 설정에 못박힌 지시. 비용과 시간이 조용히 불어난다.

## 2026-08-21 · 화면 대비 답답한 레이아웃을 방치하지 말 것
- **무엇**: 관리자 메일함이 4K 화면에서 목록/본문을 1:1로 나눠 본문이 좁았다.
  운영자 호소: "해상도 대비 메일이 너무 작게 차지한다".
- **왜**: 운영자의 실제 작업 환경은 맥미니 M4 + 모니터 3대다. 데스크톱 관리자
  화면을 노트북 기준으로 짜면 매번 좁다. 넓은 화면에서 **읽는 영역이 주인공**이
  되도록 배치하고, 필요하면 전체화면 보기를 준다.

## 2026-08-21 · 본문이 안 보이는데 "이유는 모르겠다"로 끝내지 말 것
- **무엇**: 메일 본문이 iframe 차단으로 안 보였다. 원인(확장/브라우저 정책)을
  특정 못 한 채로 방치하면 안 된다 → 프레임 의존 자체를 걷어냈다.
- **왜**: 운영자에게 "브라우저 탓"은 해결이 아니다. **우리 쪽에서 통제 가능한
  구조로 바꾸는 것**이 해결이다.

- **시크릿 커밋 금지.** `git add -A` / `git add .` 대신 파일을 명시한다.
- **`/admin` 경로 변경 금지.** 점검 도구가 이 경로를 고정으로 쓴다.
- **민감정보 저장 금지.** 카드번호 전체·신분증 번호 등. 카드 뒤 4자리만.
- **npm 패키지 임의 추가 금지** (공개 사이트). 먼저 제안한다.
- **기능을 조용히 없애지 말 것.** 제거하면 변경 로그에 명시한다.
